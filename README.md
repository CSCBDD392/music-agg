# 三家聚合搜索

一个输入框，同时搜 **酷狗 · 网易云 · QQ音乐**，结果按匹配度混排，点一下就播。

零依赖：只用 Python 标准库起一个本地网站，所有音频都通过本机代理转发（解决跨域和防盗链），
浏览器里 `<audio>` 直接能播。

```
输入「晴天」
   └─▶ 酷狗 / 网易云 / QQ音乐  三路并发搜索
         └─▶ 打分混排 → 酷狗 晴天 周杰伦 (21.0)
                         QQ   晴天 周杰伦 (20.2)
                         网易云 晴天(深情版) (12.6)
                └─▶ 点播放 → 取直链 → 拿不到就换一家同名的 → 浏览器播放
```

## 跑起来

前提：本机有这三个音乐 API 在跑（跟弹幕点歌机用的是同一批）：

| 源 | 默认端口 | 项目 |
| --- | --- | --- |
| 酷狗 | `4000` | `KuGouMusicApi`（`node app.js`） |
| 网易云 | `3000` | `NeteaseCloudMusicApi` / `api-enhanced`（`node app.js`） |
| QQ音乐 | `3300` | `QQMusicapi`（`node src/server.js`） |

```bat
python server.py
:: 打开 http://127.0.0.1:8800
```

端口跟默认不一样，写进 `config.local.json`（**注意存成无 BOM 的 UTF-8**）：

```json
{ "music": { "netease": { "port": 3001 }, "qq": { "port": 3301 } } }
```

默认只听 `127.0.0.1`。想让局域网/公网访问：

```bat
python server.py --host 0.0.0.0 --port 8800
```

> 注意：暴露到公网等于把这台机器上的三个音乐 API 也间接开放了，加反代鉴权。

## 接口

| 路径 | 说明 |
| --- | --- |
| `GET /` | 单页界面 |
| `GET /api/status` | 三家通不通 |
| `GET /api/search?q=晴天&n=8` | 混排搜索结果 |
| `GET /api/resolve?song=<URL编码的JSON>&skip=kugou` | 取直链（同源失败自动跨源找同名） |
| `GET /api/stream?song=<URL编码的JSON>` | 代理音频流，给 `<audio>` 用 |

`/api/search` 返回示例：

```json
{
  "ok": true, "keyword": "晴天",
  "songs": [
    {"source": "kugou", "id": "B3A5...", "hash": "B3A5...", "album_id": 966846,
     "title": "晴天", "artist": "周杰伦", "album": "叶惠美",
     "duration": 269, "score": 21.0}
  ]
}
```

## 打分规则

同一套规则，做成可解释的：

| 情况 | 分 |
| --- | --- |
| 标题完全等于关键词 | `+20` |
| 标题包含关键词 | `+12` |
| 关键词包含标题 | `+6` |
| 标题不搭 | `-8` |
| 歌手就是关键词 | `+6` |
| 标题含 live / 伴奏 / dj / 翻唱 / remix / 片段 / cover / 纯音乐 | `-5` |
| 歌手含 儿歌 / 童声 / 翻唱 / cover | `-6` |
| 时长 < 60 秒（多半是试听片段） | `-6` |
| 来源加权 | 酷狗 `+1.0` · 网易云 `+0.6` · QQ `+0.2` |

来源加权是因为实测酷狗取直链最稳（QQ 没登录时一律「无权限」）。

## 跨源兜底

酷狗那条如果恰好是 VIP 歌、取不到直链，程序会拿着**同名**去另外两家找，
有免费完整版就直接顶上。所以在网页上点「晴天 - 周杰伦」，最终出声的可能是一条
「晴天 - 某翻唱」，界面上会标「（来自网易云）」。

不想兜底就点「跳过」按钮把那个源排掉。

## 踩过的坑

- **酷狗搜索参数**：是 `keyword`（单数），而且 `filter=2` 会一条都不给，得用 `filter=10`。
- **搜索结果带高亮标签**：`<em>晴天</em>`，不剥掉标题就带尖括号。
- **酷狗直链列表**：`data.url` 是个**数组**，`/yp/full/` 是完整版、`/yp/p_` 是 60 秒试听，
  要优先完整版。
- **QQ 搜索必须 POST** `/search/byType` `{keyword,num,type:0}`，歌曲列表在
  `data.body.item_song`（是列表，不是含 `list` 的对象）。
- **`config.local.json` 别存成带 BOM 的**：PowerShell 的 `Out-File` 默认带，
  程序用 `utf-8-sig` 兜了一层，但最好直接存无 BOM。

## 和 danmuji 的关系

| 仓库 | 是什么 |
| --- | --- |
| [danmuji](https://github.com/CSCBDD392/danmuji) | 桌面端：B 站点歌机 + 弹幕面板（Python + tkinter） |
| **music-agg**（本仓库） | 网站：三家音乐源聚合搜索 / 播放 |

两边的 `source.py` 是同一套适配逻辑的两份拷贝——网站不想依赖桌面项目，
宁可几十行重复。改规则要两边一起改。

## 文件

| 文件 | 说明 |
| --- | --- |
| `server.py` | 全部后端：三家适配、打分、跨源兜底、HTTP 服务、音频代理 |
| `index.html` | 单页前端，无构建、无框架 |
| `config.json` | 源顺序与端口 |
| `config.local.json` | 本机覆盖（不入库） |
